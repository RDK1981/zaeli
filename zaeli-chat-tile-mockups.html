Design notes
  • Tile shape — matches existing Home tile radius (22px) + padding (18px). Same click-to-navigate pattern as Calendar / Shopping / Reminders tiles.
  • Tap — routes straight to Chat (no intent — just opens chat with input focused). If you want mic-primed, that's a second variant.
  • Icon — emoji chosen per window (☀️ 💬 👋 🌙 💤). Could swap for a single mic/chat-bubble icon that stays constant — greeting text carries the time signal.
  • "Late" tone — softened your original "Late night — what's up?" to "Still up? I'm here." — feels less like Zaeli's watching, more like she's around. Reversible.
  • Bg tint tokens (Variation B) morning peach midday sky afternoon mint evening lav late slate — all already in the app palette.
  • Brief lives on lockscreen only — server-scheduler still fires push at each user's scheduled morning + evening times. Row still written to zaeli_briefs for possible future "what was in my morning brief?" chat retrieval. Just not displayed on Home.
  • Revert Session 37 hotfix 3ad3a96 — data-signature drift regen becomes pointless if nobody reads the row live. Brief-scheduler goes back to fire-once-per-day idempotent behaviour.
