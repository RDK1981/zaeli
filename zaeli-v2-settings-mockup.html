Zaeli v2 — Settings sub-pages

Standalone Settings mockup expanding on the three role-variant top-level screens shown in the Our Family mockup (Section 4). Covers every sub-page a user taps into: Notifications, Memory, Subscription, Change password, Account/profile, and the Kid-only PIN reset flow.

Design principles

  1. Every sub-page has back-navigation in the top-left (chevron), never uses a modal for detail — one settings surface, breadcrumb style.
  2. Owner-only sections (Subscription, Delete family) are gated at the top-level; adults + kids simply don't see them. No greyed-out permission messaging — cleaner.
  3. Time pickers use inline chips, not native modal spinners. Tap the chip → sky-blue focus ring → wheel picker slides up from bottom (native DateTimePicker).
  4. Destructive actions (Sign out, Delete account, Reset PIN) live at the bottom in coral, always require confirm.
  5. PIN reset uses the same 4-dot + keypad as invite-flow onboarding — familiar surface, one visual language.
