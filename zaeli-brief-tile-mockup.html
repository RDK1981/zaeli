Brief tile — Home fallback

When a user opens the app and there's a fresh brief for the current window they haven't seen yet, a tinted card sits at the top of Home above the ChatTile. Tap to dismiss + mark seen. Time-gated so a morning brief never shows past 12pm and evening never before 4pm. Push notifications still fire for users who see previews — this catches users who don't.

Build notes

  • SQL migration: add viewed_at TIMESTAMPTZ column to zaeli_briefs. Set when user taps dismiss OR opens Chat from the card.
  • Time gate: morning card only renders 5am–11:59am; evening only 4pm–11:59pm. Same brief windows the server-side scheduler uses.
  • Freshness: only shows the LATEST brief for the current window with viewed_at IS NULL. Previous windows' briefs never resurface.
  • Load: dashboard fetches on mount + on bumpHomeRefresh. Cache to home-cache like other tiles for cold-start paint.
  • Interaction: tap card body → mark viewed + open Chat with the brief seeded as Zaeli's opener. Tap ✕ → mark viewed + card fades out.
  • Push stays: server-side scheduler + lockscreen push unchanged. This is a PARALLEL fallback for users who miss the notification.
  • Ordering: brief card sits ABOVE ChatTile. ChatTile stays as the always-on chat entry point.
