Five things about the final Bento

  • 4 core tiles, all full-width. No bento-pair, no data-lite hero. Calendar / Shopping / Reminders / Budget. Every tile earns its place.
  • Brief tile gone. Redundant with tiles. Lives in chat + on lockscreen now.
  • Reminders is the new fourth pillar. Gold accent, calls back to the "On the Radar" colour from the old Dashboard. Quick-add row. Recurring supported (12-month horizon like calendar events).
  • Budget goes silent. No "$0 left" every open. Just a beautiful nameplate you tap when you want to check.
  • Weather + Zaeli Noticed retired. iOS has weather. Zaeli Noticed data still fuels the brief and chat context — just no dedicated tile.
The Reminders bet: unique in the family-app market. Google/Apple Reminders is personal. Cozi is calendar. AnyList is shopping. None do shared family reminders with recurring + AI parsing + selective push. This is the pillar that says "Zaeli remembers what you'd forget."

The four reminder types

  • OVERDUE (coral chip "2 days") — anything past its date but not done. Sorted first.
  • TIMED (🔔 chip "7:15am") — has a specific time. Local push fires at that time to the CREATOR only.
  • DATE-ONLY (day chip "Sun") — has a date but no time. Surfaces in morning brief on that day. No push.
  • RECURRING (↻ prefix + next instance date) — repeating series. Tile shows the NEXT upcoming instance only.
  • UNDATED — never on the tile. Only in the sheet's "No date" section. So mental-note reminders don't push out time-critical ones.

Quick-add parsing (local, no AI):

  • "Take vitamins every day 8am" → daily, 08:00, timed, recurring
  • "Pack Gab's bag Thursday" → date-only, Thursday
  • "Water plants" → undated
  • "Call plumber tomorrow 3pm" → tomorrow, 15:00, timed
The Anna angle: quick-add row is the fast lane. Type "put bins out Monday nights" + Enter → recurring reminder saved. No AI overhead, no chat opens. Same speed principle as Shopping quick-add.

The sheet's five sections

  • Overdue (coral header) — everything past due, not done. Top of the list, unmissable.
  • Today (mint header) — due today (timed or date-only).
  • This week — next 6 days, sorted by soonest.
  • Later — future dates, grouped by soonest.
  • No date (subtle grey) — undated reminders. "Fix the gate" energy.

Recurring visibility — recurring reminders show as their next upcoming instance in each section, with a ↻ prefix. Tap → expand → "Change series / Just this one" options like recurring calendar events.

Attribution — small "· Anna" or "· Rich" tag next to reminders someone else created. Family-shared visibility, so you see who set what.

Tap-to-expand card actions: Edit title / Move date / Change time / Mark done / Delete / (recurring) End series after this one. Standard pattern from Calendar sheet.
04 — Brief lives on the lockscreen

Rich content on the notification, no app-open needed.

The brief is generated server-side at each family's scheduled time and pushed to family members' phones with the full content baked in. You read the whole brief on the lockscreen. Tap to open chat with the brief expanded. Don't tap → still got the summary.

The lockscreen push format

iOS lockscreen shows title (bold, one line) + body (2-4 lines before truncation). Zaeli's brief is designed to fit without truncation:

  • Title: "Morning, Rich ☀" or "Evening, Rich 🌙" — ~20 chars max
  • Body: 2-3 short sentences, ~150 chars — past-recall + today's key events + one thing. Emojis fine.
  • App icon shows the Zaeli mark (za).
  • Tap notification → app opens to Chat sheet with the brief already visible in the feed.
  • Don't tap → you still read the whole brief. That's the win.
The behavioural insight: you and Anna don't tap notifications because you're busy. So the brief needs to be USEFUL as-is on the lockscreen. Making it a summary-on-glance rather than a "tap to see more" changes everything.
Sonnet prompt constraint: the existing brief-generator prompt gets a tweak to enforce: 1 title line (~20 chars) + 1 body block (~150 chars). Same content quality, tighter shape.
05 — Server-side brief architecture

The Sonnet call moves from client to cron.

A new Supabase Edge Function runs every 15 min. It checks each family's scheduled brief time, generates the brief via Sonnet, caches it, and pushes to family members' phones with the full content. Client only reads cache when chat opens.

How it works

  • pg_cron fires the scheduler every 15 min. It queries all families whose brief time falls in the last 15 min window AND haven't been generated today.
  • For each qualifying family: gather context (events, meals, tasks, reminders, insights, memory), call Sonnet via anthropic-proxy, format for lockscreen (title + body).
  • Cache to zaeli_briefs. Same table we use today. Client-side check on chat-open sees the cached brief and displays without another Sonnet call.
  • Push to family adults via family-notify. Push payload includes the brief title + body. Lockscreen shows real content. Tap → chat opens with brief expanded.
  • Client fallback: if user opens chat BEFORE the scheduled time (edge case), client fires the brief locally. Cache stops duplication.
Cost math: ~2 briefs/family/day × ~A$0.008/brief = ~A$0.48/family/month. Same as today, but now guaranteed 2/day regardless of chat-opens (predictable, no runaway).
Optimisation for scale: only generate for families that have at least one push token registered AND have opened the app in the last 14 days. Cuts ~10-20% of Sonnet calls at scale (dormant families).

09 — Cleanup — what dies

Final list of removals.

  • ❌ Brief tile on Dashboard — moves to Chat sheet + lockscreen push. Bento gains real estate.
  • ❌ Weather tile — iOS has this natively. Removed.
  • ❌ Zaeli Noticed tile — data (family_insights) still fuels brief/chat context. No dedicated tile.
  • ❌ Chat tile — chat bar is always visible one thumb below. Tile redundant.
  • ❌ Coral mic FAB — mic is on the chat bar now.
  • ❌ ActionBar concept — retired before it shipped. Chat bar covers all the same intents with tested code.
  • ❌ MoreSheet component — hamburger goes directly to Settings sheet.
  • ❌ Client-side brief firing on app-open — server-side scheduler handles it. Client reads cache.
  • ❌ Budget financial numbers on tile — no more "A$0 left" anxiety. Tile is a minimal tap-through only.
  • ❌ our-budget.tsx as full-page route — becomes a 92% sheet like Calendar/Shopping/Reminders.
What's added: Reminders (data + tile + sheet + 92% + recurring) · Universal chat bar rendered on Bento · Hamburger back top-right · Server-side brief scheduler Edge Function · pg_cron trigger · Rich lockscreen push notifications · Notify chip on every tool confirmation.
Net direction: Bento is cleaner (4 tiles vs the old 5+). Chat is where Zaeli's personality genuinely lives. Brief is on the lockscreen where you can read it without opening the app. Reminders adds a real family-differentiator. Budget stops being an anxiety trigger. The whole v2 pattern reads as calm, honest, useful.
