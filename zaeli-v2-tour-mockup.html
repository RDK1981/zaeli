Zaeli v2 — Getting-started tour

6 stops, card-based walkthrough that fires immediately after onboarding. Same visual mechanic as the Session 19 tour but trimmed for v2 (Tutor + Kids Hub + Travel + My Space + Meals all hidden — no HERO stop). Each stop shows the actual tile/screen in miniature so the user recognises what they're about to see when they tap the CTA.

Design principles

  1. Fires automatically post-onboarding — no "want a tour?" offer. Skip button always visible top-right so anyone in a hurry can bail.
  2. Every stop has a Try saying… callout — plants the mic idea early, and gives the user a concrete first thing to say when they land in the app.
  3. CTAs open the real thing, not a mock — tapping "Open Calendar" opens the actual Calendar sheet. Tour reappears after they close the sheet, resuming at the next stop.
  4. No HERO stop — the Session 19 tour had Tutor at stop 7 with violet + trial badge. That's gone in v2. Everything's flat and equal in importance.
  5. Coral progress bar animates smoothly between stops so the user sees forward motion.
  6. Persists to tour_state profile column (Session 21 pattern) — pick up where you left off if you close the app mid-tour.

The mechanic
State + navigation notes
Fires Post-onboarding finale sets tour_offer_pending=true. Chat mount detects, pushes the "You're in! Show me around?" prompt as first Zaeli message. Tap CTA → router.navigate('/tour').
Stops STOPS array in lib/tour-state.ts — 6 entries. Each: { id, emoji, h1, sub, tryText, cta, ctaTarget, accent }. Refactor the Session 19 STOPS from 11 → 6.
Persistence profiles.tour_state JSONB (Session 21 pattern). Field: { currentStop, startedAt, completedAt, lastOpenedAt }. Kid accounts already have the effective-stops filter (Session 19 quick wins) — untouched, still works.
CTA → sheet Each stop's CTA sets pendingChatContext then navigates to swipe-world. Home consumes the context, opens the sheet. When the sheet closes, router.navigate('/tour') resumes at the next stop (via tour_resume_next=true flag).
Skip "Skip →" jumps to finale (stop 6) with progress bar filled. completeTour() marks done. Never reappears unless triggered from Settings → Replay tour.
Resume If lastOpenedAt > 24h and completedAt is null, the "Welcome back" resume screen (frame 8) fires on next app open. Continue / Skip / Dismiss. Dismiss = completeTour() too (soft giving up).
Cost Zero AI cost — no Sonnet calls, no runtime data. Pure static content. Refactor of existing Session 19 tour system, not new infra.
